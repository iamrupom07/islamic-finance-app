APPLY BACKEND UPDATE
1. Back up the repository and deployment database. Extract this ZIP at the monorepo root.
2. Remove only paths in amanah-backend/FILES_DELETED.txt. Root .github/workflows files belong at the monorepo root.
3. Keep your existing .env and secrets. Free pricing needs no GOLD_API_KEY / EXCHANGE_RATE_API_KEY. DATABASE_URL and DIRECT_URL must point to the intended database (direct migration URL preferred).

From amanah-backend (Node 24 LTS, pnpm 11.25):
pnpm install --frozen-lockfile
pnpm prisma:generate
pnpm db:migrate:deploy
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test
pnpm openapi:check
pnpm build
pnpm job:refresh-rates
pnpm dev

Run integration tests only against an isolated amanah_test* database:
Set TEST_DATABASE_URL and DIRECT_URL to that database using your shell, then run:
pnpm db:migrate:deploy
pnpm test:integration

Optional, only after qualified review supplies a real approved policy JSON:
pnpm policy:import /absolute/path/approved-zakat-policy.json
Select the imported policy in app settings. Configure PRAYER_POLICY_PATH to a reviewed prayer JSON and restart. The provided approved:false template must not be enabled.

Deployment: rebuild the same API/job Docker image; apply migration before promotion. The private job needs the DB secret, no paid market-provider secrets. Deploy the daily scheduler and verify a real successful publication. Follow the runbook; local code checks do not deploy cloud services.
